## 기본 설치

1. [파일 다운로드 페이지](https://www.couchbase.com/downloads/?family=couchbase-server) 에서 `Server` 를 클릭하고 `Community` 또는 `Enterprise` 를 선택한다. 그리고 원하는 버전과 OS(Window)를 선택하고 `Download` 를 눌러 Installer를 다운 받는다.

	![[example1-locally-window.png]]

2. 다운 받은 `Installer` 를 실행해 `Couchbase Server` 를 설치한다. 

	 ![[Pasted image 20250110220834.png]]

3. Web에 다음 주소를 `http://localhost:8091/ui/index.html` 입력해서 Web Console을 실행한다.

	![[example3-locally-window.png]]

4. 그 다음은 `Setup New Cluster` 를 눌러 새 클러스터를 설정한다. (기존 클러스터 가입은 [[Join Existing Cluster]] 에서 할 수 있다.)
5. 이제 다음과 같은 창이 나오는데 필드를 입력하여 클러스터를 만들 수 있다.

	![[example4-locally-window.png]]
	
	- **Cluster Name** : 생성할 클러스터의 이름([클러스터 및 노드 명명](https://docs.couchbase.com/server/current/learn/clusters-and-availability/nodes.html#naming-when-creating-a-single-node-cluster))
	- **Create Admin Username** : 관리자 사용자 이름을 만들기, 이 클러스터의 전체 관리자, 모든 Couchbase Server 리소스에 대한 읽기-쓰기 액세스 권한이 있다. `( ) < > @ , ; : \ " / [ ] ? = { }` 특수 문자들이 이름에 들어가면 안된다.
	- **Create Password** : 비밀번호(최소 6자리)
	- **Confirm Password** : 비밀번호 확인

6. 약관 동의 화면에서 약관 동의를 진행

	![[example5-locally-window.png]]

7. 다음으로 `서버 구성 창` 이 나오는데 각 필드는 다음과 같다.

	![[example6-locally-window.png]]
	
	- **Host Name / IP Address** : 이 노드에서 사용될 이름을 결정, 루프백 주소(127.0.0.1)로 채워져 있고, 클러스터에 두 번째 노드가 추가 될 때 까지 사용할 수 있다. 기본 호스트 IP 주소를 대체하거나 정규화 된 호스트 이름이 있는 경우 대체할 수 있다.
	
	- **enable node encryption** : 클러스터에 대한 *노드 간* 암호화를 사용하도록 설정하려면 확인란을 선택한다.

	- **IP Family Preference** : IPv4 , IPv6 , IPv4-only(IPv4 주소 패밀리만 사용) , IPv6-only(IPv6 주소 패밀리만 사용)을 선택할 수 있다.
	
	- **Service Memory Quotas** : 현재 노드와 이후 클러스터에 추가할 수 있는 각 노드에 대해 선택한 각 서비스에 할당해야 하는 메모리 양을 지정할 수 있는 필드, **모든 할당량의 합계는 현재 노드에서 사용 가능한 총 RAM의 양 내**에 있어야 한다.
		
		- **Data Service** : 데이터 서비스, 최소 256MiB 제공(기본 체크)
		
		- **Index Service** : 글로벌 보조 인덱스를 지원하기 위한 선택 및 RAM 할당, 256MiB 이상, 선택시 기본 할당량 제공.
		
		- **Query Service** : 쿼리 서비스, 이 서비스에는 RAM 할당이 필요하지 않음.
		
		- **Search Service** : 전체 텍스트 검색 서비스에 대한 선택 및 RAM 할당, 256MiB 이상, 선택시 기본 할당량 제공.
		
		- **Analytics Service** : 분석 서비스에 대한 선택 및 RAM 할당, 1024MiB 이상, 선택시 기본 할당량 제공.
		
		- **Eventing Service** : 이벤트 서비스에 대한 선택 및 RAM 할당, 256MiB 이상, 선택시 기본 할당량 제공.
		
		- **Backup Service** : 쿼리 서비스, 이 서비스에는 RAM 할당이 필요하지 않음.
		할당한 총 메모리 할당량은 필드 아래 오른쪽에 표시된다. 
		사용 가능한 총 RAM은 그림 아래 중앙에 표시된다. 
		메모리 할당량이 과도하면 알ㄹ미이 표시되고 할당량을 줄여야함.
	
	- **Data Disk Path** : 데이터베이스 파일이 저장될 현재 노드의 위치를 입력, OS별 기본값이 제공, 읽기 전용 Free 필드는 이 위치에 대한 현재 여유 공간의 양을 표시한다.
	
	- **Index Storage Setting** : `Index Service` 가 선택된 경우 라디오 버튼을 통해 `Standard Global Secondary Indexes` 또는 `Memory-Optimized Global Secondary Indexes` 를 선택할 수 있다.  프로덕션 환경에서는 데이터와 인덱스가 동일한 위치를 공유 하지 않는 것이 좋다. 
	
	- **Indexes Disk Path** : 인덱스가 저장될 현재 노드의 위치를 입력, OS별 기본값이 제공, 읽기 전용 Free 필드는 이 위치에 대한 현재 여유 공간의 양을 표시한다.
	
	- **Eventing Disk Path** : 이벤트 데이터가 저장될 현재 노드의 위치를 입력, OS별 기본값이 제공, 읽기 전용 Free 필드는 이 위치에 대한 현재 여유 공간의 양을 표시한다.
	
	- **Analytics Disk Paths** : 인덱스가 저장될 현재 노드의 위치를 입력, OS별 기본값이 제공, 읽기 전용 Free 필드는 이 위치에 대한 현재 여유 공간의 양을 표시한다.
	
	- **Java Runtime Path** : 원하는 경우 `Analytics Service` 에 사용하려는 현재 노드의 대체 JRE(Java Runtime Environments)가 사용된다. 

8. 이제 만들어진 클러스터에 대한 `Dashboard` 가 나온다.

	![[example7-locally-window.png]]

9. 서비스 실행/종료(Window)

	- 서비스 실행
	
	```CMD
	net start couchbaseserver
	```
	
	- 서비스 종료
	
	```CMD
	net stop couchbaseserver
	```

10. Couchbase 삭제

	1. 응용 프로그램 제거 : `시작 설정 > 앱 > 애플리케이션 목록 > Couchbase Server` 제거
	
	2. 데이터 및 로그 디렉토리 제거 : `C:\Program Files\Couchbase` 폴더 삭제(설치 시 기본 위치가 아닌 경우 그 경로에 `Couchbase` 폴더를 삭제해야 함)
