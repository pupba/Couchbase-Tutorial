## Docker 설치

먼저 `Docker`를 설치해 docker 이미지를 받아와 실행할 수 있는 환경을 세팅한다.

- [Window](https://docs.docker.com/desktop/setup/install/windows-install/)

- [Mac](https://docs.docker.com/desktop/setup/install/mac-install/)

- [Linux](https://docs.docker.com/desktop/setup/install/linux/)


## Couchbase 서버 설치

각 OS에 따라 `Terminal` 또는 `CMD` 를 열고 다음 명령을 입력한다.

```Shell
docker run -t --name db -p 8091-8096:8091-8096 -p 11210-11211:11210-11211 \ couchbase/server:enterprise
```

명령 실행 시 `Docker` 가 `Couchbase Server` 를 다운로드하고 설치한다. 

Server가 시작되면 다음 메시지가 표시된다.

```shell
Starting Couchbase Server -- Web UI available at http://<ip>:8091
and logs available in /opt/couchbase/var/lib/couchbase/logs
```

Server를 실행하는 동안에는 콘솔을 닫으면 안된다. 닫게되면 Server가 종료됨.
(닫고도 계속 실행하고 싶다면 Background Process로 실행)

이후 Cluster 세팅은 [[01. Couchbase-Install-Locally-Window]]과 동일하다.
